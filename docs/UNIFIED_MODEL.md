# Unified Collatz Operator Model

This note records the project's current synthesis. It is a research scaffold,
not a proof of the Collatz conjecture.

## Core Object

The shared object is a first-return/transfer operator for Collatz dynamics. In
the infinite setting this is closest to Mori's operator-algebraic picture:
partial maps corresponding to

- `T_1`: the odd branch `n -> 3n + 1`,
- `T_2`: the even branch `n -> n/2`.

Mori studies the C*-algebra generated by these maps on a Hilbert space and
relates the absence of non-trivial reducing subspaces to Collatz orbit
equivalence. Tao studies the same dynamics through the Syracuse accelerated map
and the induced `3`-adic random variables. Hercher studies cycle obstructions
through parity/valuation constraints. Paparella studies finite adjacency
truncations. Our code studies finite residue and renewal projections.

The working finite model is therefore:

```text
M_k = lift-averaged dyadic quotient of T_1 + T_2 on residues mod 2^k.
```

The lift average is essential. Division by two is not well-defined on
`Z/2^k`: an even residue has two possible halves modulo `2^k` depending on the
lift modulo `2^(k+1)`. The report averages those two lifts.

## What This Does And Does Not Say

This does say:

- The main computational threads are now represented as projections of one
  finite transfer-operator picture.
- Tao's fixed-iterate `3`-adic mechanism is reproduced by the orbit sampler.
- The renewal Cramer rate is stable across many starting magnitudes.
- The dyadic lift-averaged quotient has a stable spectral feature at `1/2`.
- Finite Paparella truncations show no non-trivial cycles in the tested windows.

This does not say:

- The infinite Collatz operator has a spectral gap.
- Mori's reducing-subspace condition has been verified.
- Tao's asymptotic superpolynomial Fourier decay has been proved
  computationally.
- Paparella nilpotency has been checked beyond finite truncations.
- The Collatz conjecture is proved.

## Gaps To Close

1. **Function space.** The right infinite space is probably not plain
   `ell^2(N)`. A scale-localized logarithmic `L^2`, weighted BV, or Hardy-type
   space is more compatible with Tao's proof.
2. **Quasi-compactness.** The finite spectral data needs a real
   Lasota-Yorke/Hennion/Ionescu-Tulcea-Marinescu style inequality before it can
   become an infinite-dimensional theorem.
3. **First-return alignment.** The first mixed `2^k x 3^ell` first-return
   quotient is now implemented. The next gap is scaling it and proving that the
   lift-averaged finite quotients converge to a meaningful operator on an
   explicitly chosen function space.
4. **Cycle-spectral bridge.** Hercher's parity-vector/Christoffel constraints
   are not yet derived from spectral data. They remain an arithmetic projection
   rather than a consequence of the operator model.
